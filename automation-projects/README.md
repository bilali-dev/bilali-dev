# 🤖 Automation Projects — n8n, Make & Zapier

Portfolio of no-code/low-code automation workflows built with **n8n**, **Make (Integromat)** and **Zapier**, focused on turning repetitive business tasks into reliable automated pipelines — API integrations, data extraction, notifications and reporting.

## Projects

| Project | Tool | What it does |
|---|---|---|
| [API to Spreadsheet](./n8n-api-to-spreadsheet) | n8n | Fetches data from a REST API on a schedule and appends it to a Google Sheet / Excel file |
| [Lead Notification Scenario](./make-lead-notification-scenario) | Make | Watches a CRM/form for new leads and sends a formatted Slack + email alert |
| [Form to Sheets Zap](./zapier-form-to-sheets-zap) | Zapier | Syncs new form submissions into a spreadsheet and sends a confirmation email |

Each folder contains a `README.md` explaining the use case, the step-by-step flow, and — where the tool supports it — an importable workflow file.
