# bot/ — Bot de Telegram

Bot base em Python usando [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot).

## Comandos disponiveis

- `/start` - inicia a conversa
- `/help` - lista os comandos
- `/status` - verifica se o bot esta ativo

Qualquer outra mensagem de texto e repetida de volta (echo), servindo como ponto de partida para novas funcionalidades.

## Como rodar

Veja a configuracao geral (dependencias, `.env`) no [README principal](../README.md).

```bash
python bot/main.py
```
